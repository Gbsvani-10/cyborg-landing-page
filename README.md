## 🌌 About the Project

**CYBERNEX** is a futuristic web experience inspired by the evolution of human-machine interaction.

It explores a world where artificial intelligence, advanced robotics, and human intelligence converge to shape the future.

Designed with a premium cyberpunk aesthetic, CYBERNEX combines immersive visuals, neon-inspired interfaces, interactive components, and smooth animations to create an engaging digital experience.

## ✨ Key Features

- 🎭 **Cinematic Hero Section** – Immersive futuristic visuals and animated backgrounds.
- 🤖 **Build Your Own Cyborg** – Customize a virtual cyborg with futuristic robotic enhancements.
- 🧠 **Neural Network Explorer** – Explore interactive neural network visualizations.
- 💬 **AI Assistant** – Interactive assistant for exploring AI and robotics concepts.
- 💻 **Cyber Command Center** – Futuristic terminal with interactive commands.
- ⚖️ **Human vs Machine** – Explore the relationship between human and artificial intelligence.
- 🚀 **Evolution Timeline** – Discover developments in AI, robotics, and human-machine interfaces.
- 🌐 **Responsive Design** – Optimized for desktop, tablet, and mobile devices.
- 🎨 **Modern UI/UX** – Neon lighting, glassmorphism, animations, and futuristic typography.

## 🚀 Getting Started

Follow these steps to run the project locally.

### 1. Clone the repository

```bash
git clone https://github.com/YOUR-USERNAME/cyber­nex.git
```

### 2. Navigate to the project folder

```bash
cd cybernex
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

### 5. Open in your browser

Visit the local URL displayed in your terminal, usually:

```text
http://localhost:5173
```
